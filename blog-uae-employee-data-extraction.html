How to Extract UAE Ministry of HR Employee Data from PDF

Published 2 June 2026  ·  5 min read  ·  By Irshadkarakkoth

The UAE Ministry of Human Resources and Emiratisation (MOHRE) issues employment list PDFs that contain full employee records — passport numbers, person codes, nationalities, job titles, card numbers and expiry dates. Manually copying this data into a spreadsheet is error-prone and time-consuming. EMPWPSCTR automates the entire process in your browser, with no software to install and no data ever leaving your device.

What Data Gets Extracted?

For each employee the tool extracts:

  • Passport Number — primary identifier from the PDF
  • Person Code — 14-digit MOHRE identifier
  • Full Name — English only, Arabic stripped automatically
  • Job Title — as listed on the work permit
  • Nationality — supports 50+ nationalities
  • Card Number — Emirates ID or permit card number
  • Expiry Date — work permit expiry, colour-coded on export
  • Company Code — establishment number from the PDF header
  • Source File — which PDF each record came from

Step-by-Step: Extracting Employee Data

1

Open EMPWPSCTR and log in

Go to the EMPWPSCTR app and enter your login credentials. Accounts are managed by your system administrator.

2

Select the Employee List tab

Click Employee List in the top navigation bar. You will see the drop zone and an empty data table.

3

Upload your MOHRE PDF files

Drag and drop one or more employment list PDFs onto the drop zone, or click Browse Files. Multiple files are supported — records from all files are merged into one table.

4

Click Extract

The app reads each PDF entirely in your browser using PDF.js, parses employee records and populates the table. A progress bar shows the status for large batches.

5

Filter and search

Use the global search box, or the nationality / job / file dropdowns. Per-column filter inputs let you narrow down by name, passport number, expiry date and more.

6

Export to Excel

Click the Excel button. Choose With Colors to get red / orange / yellow / green expiry highlighting, or Without Colors for a plain file.

💡 All processing happens entirely inside your browser — no employee data is uploaded to any server. Your records stay private.

Supported PDF Formats

EMPWPSCTR supports the standard MOHRE employment list format with columns for Passport Number, Person Name, Person Code, Card Type, Job Name, Nationality, Card Number, Contract Type and Expiry Date. Both paginated multi-page PDFs and single-page lists are handled automatically.

Frequently Asked Questions

Can I process multiple PDFs at once?

Yes. You can upload many PDF files simultaneously. Records from all files appear in one combined table, and the Source File column shows which PDF each row came from.

What if some rows are missing?

The info bar above the table shows the PDF-reported total employee count versus the number extracted. If counts differ, the PDF may contain scanned images rather than digital text — only text-based PDFs can be parsed.

Is my data sent to any server?

No. PDF parsing and Excel export run entirely in your browser using JavaScript. No file content or employee data is transmitted anywhere.
